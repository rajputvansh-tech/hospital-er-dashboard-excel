
# 🏥 Hospital Emergency Room Dashboard (Excel)

An interactive Excel dashboard that tracks ER performance by month and year.


## Features
- KPI cards: number of patients, average wait time, satisfaction score
- Delay vs. on-time split
- Patients by age group and gender
- Admitted vs. not admitted
- Referrals by department
- Month and year slicers for filtering


## Key Insights
- About 60% of patients experienced delays
- Satisfaction stayed high (4.7-4.9)
- Admissions were around 50-55% each month
- Most patients had no specialty referral; General Practice and Orthopedics lead the rest


## Tools Used
Microsoft Excel, Pivot Tables, Slicers, Charts


## How to Use
Download the .xlsx file and use the month/year slicers to explore the data.
